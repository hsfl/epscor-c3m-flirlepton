1) Open terminal and go to the repo:
cd epscor-c3m-flirlepton

2) Run data collection:
# Linux:
python3 readout.py

# macOS:
sudo python3 readout.py

3) If you get uvc_open error (Access denied), verify access with:
# Linux quick test fix:
sudo chmod -R 777 /dev/bus/usb/
python3 uvc-deviceinfo.py
python3 readout.py

# macOS:
sudo python3 uvc-deviceinfo.py
sudo python3 readout.py

Recent macOS versions may require root (or app entitlements) for libusb/libuvc access.
On Linux, prefer a udev rule over chmod 777 for long-term use.

4) To stop data collection:
Press Ctrl+C in the capture terminal.

5) To view data:
python3 npz_viewer.py
# or for .bin frames:
python3 binary_viewer.py

6) To avoid overwriting output, change save directory/file names in code as needed.
